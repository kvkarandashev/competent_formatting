# competent_formatting

For convenient presentation of data in LaTeX. The resulting LaTeX output is "competent" in looking nicely in PDF regardless of LaTeX packages or document classes used (though not necessarily "nice" due to phantom character overuse). Contains procedures for creating tables, cleaning revision markup out of LaTeX sources, `cf_quick_table_view`, which compiles a generated table on its own so it can be looked at or checked for fitting the text width, and `cf_view`, a local web viewer that recompiles a manuscript and its SI on demand (see AGENTS.md).
